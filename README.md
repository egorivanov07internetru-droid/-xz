# 💜 Duora

Duora — приватное приложение для общения двух человек.

## ✨ Возможности

- 🔐 Подключение по коду
- 🔢 Код формата `XXX-XXX`
- ⏱️ Код действует 5 минут
- 👥 Максимум 2 человека в комнате
- 💬 Приватный чат
- 😀 Стикеры
- 🖼️ Создание собственных стикеров из галереи
- 🎙️ Голосовой чат — отдельная функция

## 🔗 Как работает

1. Первый человек нажимает **«Сгенерировать код»**.
2. После генерации получает код.
3. Второй человек нажимает **«Присоединиться по коду»**.
4. Вводит полученный код.
5. Оба попадают в одну комнату.
6. Открывается `chat.html`.

## 📁 Файлы

- `index.html` — главный экран и подключение
- `chat.html` — чат
- `server.js` — сервер комнат и WebSocket
- `package.json` — зависимости проекта
